Why this layer

The visit FSM already understands a spoken day and time. The miss is chrome: a list of weekday names. A Flow is the only WhatsApp surface that can draw a month. We do not teach a new intent, and we do not replace the FSM. The Flow completes into the same words the list already produces.

Send (Cloud API)

{
  "type": "interactive",
  "interactive": {
    "type": "flow",
    "body": { "text": "Which day works for Brigade Eternia?" },
    "action": {
      "name": "flow",
      "parameters": {
        "flow_message_version": "3",
        "flow_id": "WA_VISIT_FLOW_ID",
        "flow_cta": "Pick a day",
        "flow_action": "navigate",
        "flow_action_payload": {
          "screen": "DATE",
          "data": {
            "min_date": "2026-09-15",
            "max_date": "2026-09-28",
            "project_name": "Brigade Eternia"
          }
        }
      }
    }
  }
}

Return (webhook)

interactive.nfm_reply.response_json
  { "date": "2026-09-15", "time": "10:30 AM" }

→ canonical text the visit FSM already parses:
  "2026-09-15 at 10:30 AM"
